# Questions to Ask an Edtech AI Vendor

An open question bank for school and district leaders who need to vet AI products before buying them.

Every question comes with two notes:

- **Why it matters:** what the question is really testing.
- **What a weak answer sounds like:** how to recognize an answer that sounds reassuring but doesn't hold up.

The second note is the point of this project. Most checklists tell you what to ask. This one helps you judge the answer.

## Use it

Open the questionnaire page, choose the questions you need, then copy or print a clean list to send to a vendor. No account, no tracking, no data collected.

Or read the questions directly in [`data/questions.json`](data/questions.json).

The privacy section is intentionally short. Strong privacy resources already exist, including the [Student Data Privacy Consortium](https://privacy.a4l.org/). This project focuses most on evidence of impact, where vendor claims are hardest for schools to check.

## Contribute

Suggestions from educators are the main way this grows.

- **Suggest a question:** open an issue with the question, why it matters, and what a weak answer sounds like.
- **Improve an existing question:** open an issue or pull request that references its ID (for example, `EV-03`).

Ground rules:

- No vendor or product names, and no ratings of real products. This is about questions, not reviews.
- Keep questions answerable. A vendor should be able to respond in writing.
- Plain language. Write for a principal reading between meetings, not a researcher.

## Limits

- **Not legal advice.** Privacy and contract questions should be checked with your district's legal and data privacy staff.
- **Not an endorsement system.** Good answers to these questions don't certify a product, and the questions don't cover every risk.
- **Not affiliated with any school district or organization.** This is an independent project.
